# Tutorials

These tutorials introduce PsyNeuLink's core concepts and guide you through building
models of increasing complexity. If you are new to PsyNeuLink, start with
**Getting Started** and then work through the topic-specific tutorials. The
**Basics and Primer** page contains the full introductory reference material in one place.


## Recommended Reading Order

1. {doc}`getting-started` -- Install PsyNeuLink, meet the core objects, build and run
   your first model.
2. {doc}`mechanisms-and-functions` -- Learn how Mechanisms process information and how
   Functions define their computations.
3. {doc}`projections-and-pathways` -- Understand how Projections connect Mechanisms and
   how pathways organize them.
4. {doc}`compositions` -- Build full models with Compositions, run them, inspect results,
   and visualize the graph.
5. {doc}`control` -- Add control mechanisms that monitor output and regulate processing.
6. {doc}`learning` -- Train networks with backpropagation, LearningMechanisms, and
   AutodiffComposition.
7. {doc}`basics-and-primer` -- Comprehensive reference covering all of the above in a
   single document.
